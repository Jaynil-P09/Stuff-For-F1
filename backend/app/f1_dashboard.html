Full grid

Calls GET /api/v1/grid. Tries a live session first; if none is active, falls back to a historical session you pick.

Live mode depends on OPENF1_EVENT_NAME_MAP being filled in on the backend — until then, a live session may return "Unknown event" even though data was fetched fine. Historical mode shows each driver's state at the END of the session, not a chosen lap, and has no overtake predictions yet (gap data isn't reconstructed for historical mode).
